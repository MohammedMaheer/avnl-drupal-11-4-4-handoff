# Scope of Work Traceability Matrix

Status terms are used strictly: **Complete** means implemented and evidenced in the handoff; **Manual validation required** means source work is complete but human/environment acceptance remains; **Deployment-team action** is work that can only occur on receiving infrastructure; **Contractual action** requires AVNL/vendor sign-off rather than a source change.
